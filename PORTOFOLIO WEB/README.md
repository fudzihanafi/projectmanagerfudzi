# Fudzi Hanafi Portfolio

A premium, high-end portfolio website for Fudzi Hanafi, a Product Manager & Solo Builder.

## 🚀 Features
- **Modern Design**: Built with a sleek dark mode aesthetic using HSL tailored colors.
- **Bento Grid Layout**: Showcase projects in a dynamic, responsive grid.
- **Smooth Navigation**: Enhanced user experience with smooth scrolling and micro-interactions.
- **Responsive**: Fully optimized for all screen sizes (Desktop, Tablet, Mobile).
- **SEO Optimized**: Built with semantic HTML and meta tags for better search visibility.

## 🛠️ Tech Stack
- **Structure**: HTML5
- **Styling**: Vanilla CSS3 (Custom Design System)
- **Interactions**: Vanilla JavaScript
- **Icons**: FontAwesome 6
- **Typography**: Google Fonts (Urbanist & Inter)

## 📂 Folder Structure
```text
├── css/

├── js/

├── index.html         # Main entry point

```

## 🌐 Hosting on GitHub Pages
1. Push this folder to a new GitHub repository.
2. Go to **Settings** > **Pages**.
3. Select the `main` branch as the source.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
